# ABTalks Redesign

A mobile-first redesign of ABTalks built around a 60-day coding challenge experience.

The goal is to make daily building, progress, and proof of work feel clear and motivating for students.

## ✨ What I Built

- Mobile-first ABTalks landing page
- Student dashboard with challenge progress
- Day 12 challenge experience
- GitHub + LinkedIn proof-of-work submission
- Streak and achievement tracking
- Missed-day recovery state
- Incomplete-profile state
- Responsive layouts optimized for a 390px mobile viewport
- Interactive completion state for challenge submissions

## 🧭 Routes

| Route | Purpose |
|---|---|
| `/` | ABTalks landing page |
| `/dashboard` | Student dashboard |
| `/day/12` | Day 12 challenge experience |

## 🛠 Tech Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS
- App Router
